# ERD for E-Commerce Project

Design an Entity Relationship Diagram (ERD) for a simple e-commerce system.

Requirements

•	Create an ERD using draw.io, Lucidchart, or any similar tool.
•	Include at least these tables: 
   o	Users — user data
   o	Products — product data
   o	Categories — product categories
   o	Orders — customer orders
   o	Order Items — details of each order
•	Define the proper relationships between tables (One-to-Many, Many-to-Many, etc.)
•	Export the final diagram as an image (PNG or JPG).

Topics Covered
ERD · Database Design · Relationships · ACID
